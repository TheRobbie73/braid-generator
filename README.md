Uses the python Pillow library to generate braid pixel art. Look in `braid_generator.py` for usage.

Run `uv sync` to get dependencies, 

then `uv run src/braid_generator.py` to generate and show the image. 

Modify `braid_generator.py` directly to make your own braid.

For more information on uv and pillow: 

https://docs.astral.sh/uv/ 

https://pillow.readthedocs.io/en/stable/
